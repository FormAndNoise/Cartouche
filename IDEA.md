# Project Idea

The idea is a piece of software aimed at helping artists manage the coordination of large projects requiring complex deliverables. It provides a GUI for the artist that creates a user-defined number of sockets where:

1. An image or other document can be placed so that its presence is visible next to other images in different sockets as well as visibly empty sockets.
2. Each socket contains a space for the user-defined title or label for the socket, assorted metadata, and user notes.
3. The sockets can be viewed as individual rows that can be scrolled through, a pair of rows, or a trio of rows (up to 4 or 5 rows) to view the project progress as a grid.
4. Multiple works can be placed in a single socket for the purpose of comparison to choose a winning final piece.

## Required Features

1. Drag-and-drop functionality
2. File explorer pick and choose
3. Import CSV for fast socket and grid population when provided.
4. Ability to read documents of various kinds to include the text inside a socket data card.
5. Lock from deletion protection toggle at the individual scale.

## Dream Features

1. ComfyUI integration where the output node directly exports the generated image, prompt, and related metadata from generation to the socket and the socket card.
2. Granular LLM MCP tools providing a model with the ability to see a project through from beginning to end if necessary, or just to assist the user along the way.

## Context

I'm creating this program to help me manage the creation of a full tarot deck of 70-something individually designed cards.
